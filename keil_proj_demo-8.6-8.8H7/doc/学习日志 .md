| 命令 | 作用 | 什么时候用 |
|------|------|------------|
| git clone -b (分支名) git@github.com:(组织名)/(仓库名).git | 将本地的文件夹和远端的仓库建立关系 | 向组织仓库发布代码前 |
| git add . | 添加代码 | 文件修改完成后 |
| git commit -m "备注" | 附加改动提示 | add完成之后 |
| git push | 推送到远程仓库 | commit完成之后 |

```
git add .            //警告不用管
git commit -m "更新信息"
git push             //第一次上传可能需要git push --set-upstream origin 分支名 以建立远程连接
```
